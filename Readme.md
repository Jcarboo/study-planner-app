# Dreamer – AI-Powered Study Planner

Dreamer is a full-stack web application that helps students plan, track, and optimize their study sessions.  
It includes a planning dashboard, progress tracking tools, and integrated AI features to summarize notes, explain concepts, and generate quizzes.

---

## Features

### Study Planning
- Create and manage study plans for multiple courses.
- Add, edit, and delete tasks with deadlines.
- Track completion with progress rings and daily streaks.
- View subject-based statistics and most-completed topics.

### Progress Tracking
- Visual charts for study activity.
- Longest streak and completion rate tracking.
- Subject-based task completion breakdown.

### AI-Powered Tools
- **AI Study Tips** – Personalized learning suggestions based on your plans.
- **Notes Summarizer** – Condenses uploaded notes into concise summaries.
- **Concept Explainer** – AI-generated explanations for difficult concepts.
- **Quiz Maker** – Create multiple-choice and free-response quizzes from your notes, with AI grading.

### Profiles
- View and customize your profile.
- Public profile pages for other users.
- Search for users and courses to find study buddies.

## Tech Stack

**Frontend:**
- React (TypeScript)
- Tailwind CSS
- React Router
- Chart.js

**Backend:**
- Flask (Python)
- Flask-Login & Flask-CORS
- MongoDB (Flask-PyMongo)
- Google Gemini API for AI features

---

## How to Use

1. **Sign Up / Log In**
   - Create an account and log in to access your dashboard.

2. **Create a Study Plan**
   - Add a course, then create study tasks with deadlines.
   - Mark tasks complete as you go.

3. **Track Progress**
   - Visit your profile to view your study statistics, streaks, and most-completed subjects.

4. **Use AI Tools**
   - Navigate to the AI Tools page to:
     - Generate study tips
     - Summarize notes
     - Explain concepts
     - Create and take quizzes

5. **Manage Notes**
   - Upload notes (max 5 at a time). Delete old notes to add new ones.
   - Rename notes for better organization.
